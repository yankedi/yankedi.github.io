moco

一个用 C 语言从零编写的 Minecraft 启动器 —— 轻量、快速、透明。

GitHub 快速开始 →

概述

moco 是一个纯 C 编写的 Minecraft 命令行启动器和管理工具，目前处于 v0.1.0 早期开发阶段。它覆盖了 Minecraft 实例的完整生命周期：环境初始化、Microsoft OAuth2 登录、版本及模组加载器安装、模组包导入、版本搜索、以及最终的游戏启动。

moco 不依赖任何第三方运行时（不需要 Python、Node.js、Java 来运行自身），构建产物是一个单一静态二进制文件，可以在任何 Linux 系统上直接运行。

命令链

moco init      → 初始化工作目录和配置文件
moco login     → Microsoft OAuth2 设备码登录
moco install   → 下载 Minecraft 版本 + 模组加载器 + 模组
moco start     → 启动游戏

核心特性

极致轻量

单一可执行文件，没有 Electron 外壳，没有后台服务，没有运行时依赖。

全生命周期管理

从初始化、登录、安装到启动，一条命令链覆盖完整流程。

模组加载器支持

支持 Forge、NeoForge、Fabric 三大主流加载器，兼容 Modrinth 模组包。

内容寻址存储

基于 SHA1 校验和的智能存储，类似 pnpm 的全局去重与硬链接机制。

异步并发下载

基于 epoll + curl_multi 的自研下载引擎，最多 16 个并发连接。

安全透明

完全开源，本地优先，配置是 TOML 明文，没有遥测，不需要 root。

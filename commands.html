命令参考

命令功能说明
moco init初始化工作目录创建配置目录和默认配置文件 instance.toml
moco loginMicrosoft 账户登录通过设备码流程完成 OAuth2 认证，获取并缓存 Token
moco install下载安装下载 Minecraft 版本 jar、模组加载器及配置的模组文件
moco start启动游戏组装 classpath 和 JVM 参数，通过 fork+execvp 启动 Minecraft
moco search <关键词>搜索版本搜索可用的 Minecraft 版本和模组加载器版本
moco update更新版本清单从 Mojang API 拉取最新的版本和资源清单
moco import <文件.mrpack>导入模组包导入 Modrinth 格式整合包，自动生成实例配置

典型工作流

# 全新安装
moco init
vim instance.toml     # 编辑配置
moco login            # 登录账户
moco install          # 下载安装
moco start            # 启动

# 导入他人分享的整合包
moco import 包名.mrpack
moco install
moco start

# 切换版本
vim instance.toml     # 修改 game.version
moco install
moco start

配置文件格式

moco 使用 TOML 格式存储配置：

[game]
name = "我的实例"               # 实例名称
version = "1.20.4"              # Minecraft 版本号
# 以下字段由 moco import 自动生成，手动创建时可省略
# modpack_version = "13.2.0"
# modpack_mode = "modrinth"

[launch]
# java_path = "/usr/bin/java"   # Java 路径（可选，不填则使用自动下载的 JRE）
jvm_xms = "2G"                  # JVM 初始堆内存
jvm_xmx = "4G"                  # JVM 最大堆内存

[dependencies]
# forge = "47.3.0"              # Forge 版本（与 neoforge/fabric-loader 互斥）
# neoforge = "20.4.251"         # NeoForge 版本
# fabric-loader = "0.15.11"     # Fabric Loader 版本
# quilt-loader = "0.26.3"       # Quilt Loader 版本（暂未完全支持）

# 模组列表（选填）
[[mods]]
url = "https://cdn.modrinth.com/data/.../sodium-fabric-0.5.8+mc1.20.4.jar"
sha1 = "abc123..."
path = ".minecraft/mods/sodium-fabric-0.5.8+mc1.20.4.jar"

字段说明

字段说明
game.name实例显示名称
game.versionMinecraft 版本号
game.modpack_version模组包版本（由 moco import 自动生成）
game.modpack_mode模组包模式，目前为 "modrinth"
launch.java_pathJava 可执行文件路径（可选）
launch.jvm_xmsJVM 初始堆内存，如 2G、512M
launch.jvm_xmxJVM 最大堆内存，如 4G、8G
dependencies.forgeForge 版本号
dependencies.neoforgeNeoForge 版本号
dependencies.fabric-loaderFabric Loader 版本号
dependencies.quilt-loaderQuilt Loader 版本号（暂未完全支持）
mods[].url模组下载地址
mods[].sha1模组文件的 SHA1 校验值
mods[].path模组安装到的目标路径

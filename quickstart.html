快速开始

环境要求

  • Linux 操作系统
  • GCC 编译器（C11 支持）
  • CMake 3.14+
  • libcurl、OpenSSL、zip 开发库

安装依赖（Debian / Ubuntu）

sudo apt install build-essential cmake libcurl4-openssl-dev libssl-dev zlib1g-dev

从源码构建

git clone https://github.com/yankedi/moco.git
cd moco
make clean && make build

基本使用流程

1. 初始化

./moco init

创建配置目录和默认配置文件 instance.toml。

2. 编辑实例配置

vim instance.toml

设置 Minecraft 版本、模组加载器类型、内存分配等参数。

3. 登录 Microsoft 账户

./moco login

通过设备码流程完成 Microsoft OAuth2 认证。终端会显示一个设备码和验证链接，在浏览器中打开链接并输入设备码即可完成授权。

4. 安装

./moco install

下载 Minecraft 版本、模组加载器以及配置文件中指定的模组。

5. 启动游戏

./moco start

启动 Minecraft，开始游玩。

附加功能：导入模组包

./moco import Fabulously.Optimized-v13.2.0-beta.2.mrpack

导入 Modrinth 格式的整合包，自动生成 instance.toml 并解压覆盖文件。

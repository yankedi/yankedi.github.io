模块划分

CLI 命令层

init、login、install、start、update、search、import 七大命令，各自负责一个独立阶段。

下载引擎

基于 epoll 事件循环 + curl_multi 多路复用，支持 16 并发、进度条、自动重试。

存储层

基于 SHA1 校验和的内容寻址存储，通过硬链接实现全局去重和多实例隔离。

认证模块

Microsoft OAuth2 完整认证链：设备码授权 → XBL → XSTS → Minecraft Token。

设计理念

  • 单一可执行文件 — 编译产物是一个静态二进制，无需任何运行时依赖
  • 进程隔离 — 通过 fork() + execvp() 分离启动器进程和 Minecraft 游戏进程
  • 文件级去重 — 采用硬链接而非软链接，保障文件真实存在且可独立访问
  • 管道通信 — 下载任务通过管道提交和接收结果，解耦 CLI 线程和下载线程

路线图

v0.1.0（当前）

  • 完成基本命令：init、login、install、start、search、update、import
  • 支持 Forge、NeoForge、Fabric 三大模组加载器
  • 内容寻址存储与硬链接去重
  • 基于 epoll + curl_multi 的并发下载引擎
  • Microsoft OAuth2 完整认证链

短期：v0.2 - v0.3

自动 JRE 管理

根据 Minecraft 版本自动选择和下载匹配的 JRE（Java 运行时环境），用户不再需要手动安装 Java。

多实例管理

支持同时管理多个 Minecraft 实例（不同版本、不同模组组合），每个实例独立配置、独立启动。

跨平台支持

移植到 macOS 和 Windows 平台，覆盖全部主流桌面操作系统。

中期：v0.4 - v0.5

模组依赖解析

自动解析模组间的依赖关系，提示冲突和缺失。例如：安装模组 A 时自动提示需要前置模组 B。

模组包导出

支持将当前实例导出为 Modrinth 格式的模组包（.mrpack），方便分享给其他玩家。

长期愿景

  • 跨平台 GUI 启动器 — 一个真正原生、不吃资源的 Minecraft 启动器，对标 MultiMC / Prism Launcher，但更轻、更快
  • 语言演进 — 作者将跟随学习路线从 C 逐步转向 C++，项目实现语言可能随之迁移
